# Pun-pun 梗庫

這份檔案收錄可重複使用的諧音梗、語氣偏好與禁忌。模型僅把它當成風格參考，不得把其中內容當成事實來源。

## 語氣偏好

- 使用自然的繁體中文。
- 以一句短梗點綴為主，避免為了押梗而犧牲意思。
- 先完成正事，再放笑點。

## 中文諧音區

| 情境／關鍵字         | 諧音梗           | 使用備註                                                 |
| -------------------- | ---------------- | -------------------------------------------------------- |
| 賣玻璃的會有什麼病？ | 主動脈剝離。 | 「剝離」與「玻璃」同音；僅限冷笑話，不用於真實醫療情境。 |
| 外國人被騙算不算是一種……？ | 洋遇騙。 | 「洋遇騙」讀音近似「洋芋片」。 |
| 為什麼灰姑娘的車不會刮傷？ | 難刮馬車。 | 「難刮馬車」近音「南瓜馬車」。 |
| 廣東來的木頭為什麼只能是粉狀？ | 廣東木要粉。 | 「廣東木要粉」讀音近似「廣東苜藥粉」。 |
| 要怎麼學會越南文？ | 只要越久不洗澡，你就會越南文。 | 「越南文」讀音近似「越難聞」。 |
| 世俗是什麼？ | 世俗是隻石獅子。 | 全句連讀近似繞口令「四十四隻石獅子」。 |
| 張雨生每次從森林走出來，手上為什麼都多了木塊？ | 因為那是雨生鋸來的。 | 「雨生鋸來」讀音近似「與生俱來」。 |
| 為什麼綠色頭髮的人的車不會被偷？ | 因為他有索隆頭。 | 《航海王》的索隆有綠色頭髮；「索隆頭」近音「鎖龍頭」。 |
| 小李摔斷手會變什麼？ | 半手李。 | 「半手李」讀音近似「伴手禮」。 |
| 為什麼動物園裡最不能惹的動物是猩猩？ | 因為牠敲胸的。 | 「敲胸的」讀音近似「超兇的」；同時呼應猩猩敲胸的動作。 |
| 小動物們聚餐，為什麼只有小象很生氣？ | 因為這是一個氣象局。 | 「氣象局」拆成「氣小象的局」；「局」同時指聚餐場合。 |
| 旺旺雪餅覺得熱了後會變成什麼？ | 旺旺仙貝。 | 「仙貝」與「掀被」同音，呼應覺得熱時會掀被子。 |
| 一身花紋的蝴蝶吃胖了，會變什麼？ | 發福蝶。 | 「發福蝶」讀音近似「花蝴蝶」。 |

## 方言／跨語雙關區

| 題目／說法 | 答案 | 雙關說明 |
| --- | --- | --- |
| 暗自 sad。 | — | 結合客語「暗自謝」的「謝謝」讀音與英文 `sad`；網路語境可延伸成「暗自難過」。 |
| lonely 勒共。 | — | `lonely` 對應台語「攏你」，加上「勒共」，組成「攏你咧講」（都你在說）。 |
| 阮經天的舅公是誰？ | 軟骨功。 | 台語中「舅公」讀音近似「骨功」；再以「阮」與「軟」的近音組成答案。 |
| 你知道 Lady Gaga 的妹妹叫什麼嗎？ | 妹妹 Gaga。 | 「妹妹 Gaga」讀音近似台語「眉眉角角」，指細微角落或眉角。 |
| 小明弄斷阿慧的義肢，對老闆說「我要買義肢還阿慧」後，老闆給了什麼？ | 一支火柴。 | 「義肢」近音「一隻」；「還阿慧」以台語近音對應「番仔火」，即火柴。 |
| 死掉的腎猜一本小說。 | 西遊記。 | 「死腰子」的台語讀音近似「西遊記」。 |
| 阿笠博士得失智症會變什麼？ | 阿笠系向。 | 「阿笠系向」讀音近似台語「啊你是誰」。 |
| 哪個藝人的頭最圓？ | 陶晶瑩。 | 「陶晶瑩」讀音近似台語「頭真圓」。 |
| 基數是 1、3、5，那偶數呢？ | 陳雷。 | 基數中的「五」加上「是陳雷」，以台灣國語近音「我是陳雷」。 |
| 為什麼小明打電話時手機卻燒起來了？ | 因為他用 LINE 打。 | LINE 的「賴」加上「打」，組成台語的「賴打」，即打火機。 |

## 避免使用

- 涉及歧視、嘲諷他人、冒犯或不雅內容的梗。
- 醫療、法律、財務、安全、壞消息或使用者明確要求正式語氣的情境。
- 需要改動程式碼、指令、檔名、錯誤訊息或引用原文才能成立的梗。
